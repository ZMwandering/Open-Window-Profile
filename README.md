# Open Window Profile: Beyond Separation at the Moment of the Throw

We built a tool that measures not just *whether* a receiver is open at the moment of the throw, but *when* and *for how long* they create separation throughout the play. Using **Open Window Area** (cumulative separation over time) and **Late Availability** (whether receivers stay open in the final second before release), we analyzed 1,889 pass plays and found that targeted receivers have 50% higher late availability than non-targeted teammates, even when throw-time separation is similar. This tool helps **coaches** identify which receivers match their QB's read speed (early vs. late open patterns), **scouts** evaluate route-running beyond catch stats, and **broadcasters** explain why high-separation receivers aren't getting targets—their windows close before the QB can find them.
